# 🎮 Number Guessing Game

A simple Python-based number guessing game where the user competes against the computer.

## 🚀 Features

- Random number generation
- User input handling
- Computer-generated guesses
- Game result calculation
- Simple command-line interface

## 🛠️ Technologies Used

- Python
- Random module

## ▶️ How to Run

```bash
git clone https://github.com/saswatiwari1/number-guessing-game.git
cd number-guessing-game
python main.py
```
